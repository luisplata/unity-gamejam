# unity-rapid-prototyping

Skill de prototipado rápido para desarrollo de juegos en Unity a través del Unity MCP.

La mayoría de las skills enseñan **cómo programar**. Esta enseña **cómo decidir**: antes de proponer código, responde internamente cinco preguntas que protegen el core loop, el tiempo y las chances de terminar el juego.

## Estructura

```
├── skills/
│   └── unity-rapid-prototyping/   # La skill (SKILL.md)
├── examples/                       # Referencias por género: gate aplicado
│   ├── top-down-2d/
│   ├── platformer/
│   └── survivors/
└── docs/
    ├── philosophy.md               # Por qué decidir > programar
    ├── architecture.md             # Arquitectura mínima para jam games
    ├── workflow.md                 # Flujo Unity MCP de iteración
    └── prompts.md                  # Templates de prompts para el agente
```

## Uso

Para usar la skill en un proyecto de juego: copiala a `.opencode/skills/` del proyecto (o instalala global en `~/.config/opencode/skills/`). En este repo vive como contenido, no como skill auto-cargada.
